07 / YOUR DATA

Privacy and network transparency

Assessment content, imports, scoring and document generation run locally in this browser. This application has no backend, account, analytics or advertising. Assessment data is never included in application logs or requests.

Autosave uses IndexedDB, with browser storage as a fallback. Browser storage is neither a secure nor synchronised backup. Other users of this browser profile may access it, and clearing browsing data can remove it. Export complete JSON backups regularly.

The online edition downloads Mightora shared styles, components and js-yaml from jsDelivr, official branding images, the local shared footer snapshot and GitHub status badge images. These requests disclose ordinary connection metadata to their hosts. Assessment content is excluded. The offline edition embeds all required assets and blocks outbound application connections.

Share links include an encoded, compressed assessment snapshot in the URL fragment. Anyone possessing a link can inspect its contents. Links are not encrypted, password protected or access controlled. The summary option removes evidence, recommendations, risks, owners, notes and historical snapshots. Review remaining titles, descriptions and scores before sharing. Share URLs can remain in browser history or be copied by extensions.
