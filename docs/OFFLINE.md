# Mightora Maturity Assessment Offline Edition

Unzip the download and double-click index.html. Or open the standalone offline.html in a current desktop Chrome, Edge, Firefox or Safari browser. No installation, server or internet connection is needed on Windows, macOS or Linux.

The same maintained application source produces both editions. All JavaScript, CSS, official full Mightora logo, author images and document generation libraries are embedded. There are no remote fonts, CDNs, analytics or APIs. Content Security Policy blocks application connections. External links are ordinary links and only navigate when selected.

Choose a blank assessment, template, example or import a JSON project. Editing, charts, complete JSON and CSV import/export, autosave, Word and PowerPoint generation work locally. Save JSON regularly. Browser storage behavior for file URLs can vary; a renamed file or different browser may have a separate workspace. Browser storage is not a secure or synchronised backup. Mobile file previewers may not run JavaScript fully: the double-click edition is intended for desktop browsers.

The offline file cannot generate a useful public share URL. Import the project into the online edition to generate a link, or send the JSON through an appropriate channel. Online workflow evidence links require internet access if followed. See the in-app Guide and Privacy / Network Transparency sections for details.

The ZIP contains index.html, this README and the MIT licence. Its HTML is byte-identical to the standalone download in the same build.
